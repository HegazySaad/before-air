# قبل الهوا — بورتفوليو حجازي سعد

فيلم تفاعلي بيتفرج عليه بالسكرول: غرفة كتابة، باب كنترول، وورق سكريبت بيتقلب شاشات.
الموقع ثابت (HTML + CSS + JS) من غير خطوة build للمتصفح، وبيشتغل على GitHub Pages زي ما هو.

## التشغيل محليا

```bash
python3 -m http.server 8000
```

وافتح `http://localhost:8000`. لازم سيرفر (مش فتح الملف مباشرة) عشان الموديولات والفيديو.

## بنية المشروع

| المسار | وظيفته |
|---|---|
| `content/site.json` | **كل المحتوى التحريري**: الفصول، النصوص، الأدوار، الروابط، التترات. |
| `tools/build.py` | بيولّد `index.html` من ملف المحتوى. |
| `index.html` | الناتج. ما يتعدلش باليد. |
| `take.css` | الهوية البصرية والتخطيط، وفيه الوضع البسيط من غير 3D. |
| `take.js` | المشهد: الغرفة، الكاميرا، الشاشات، الجزيئات، التنقل. |
| `vendor/` | three.js r170 وموديولات المعالجة الرسمية (MIT). |
| `img/`, `vid/`, `fonts/` | الوسائط الحقيقية والخطوط (Aref Ruqaa وReadex Pro، رخصة OFL). |
| `v3.html` + `style.css` + `dist/` | النسخة السابقة، محفوظة كما هي. |

## تعديل المحتوى أو إضافة عمل

1. افتح `content/site.json`.
2. تحت `chapters` انسخ أي عنصر `"type": "program"` وعدّل:
   `id` (بالإنجليزي، بيبقى رابط المشاركة `#id`)، `nav`، `title`، `meta`، `lead`، `desc`، `role`، `links`، `img`.
3. اختياري: `year` (بتظهر في آلة الزمن)، `sats` (صور أو `vid:اسم` حوالين الشاشة)، `note` (ملاحظة الهامش)،
   `paper` (الجملة المكتوبة على ضهر الشاشة)، `mood` و`tint` (شخصية المشهد).
4. شغّل:

```bash
python3 tools/build.py
```

ترتيب العناصر في الملف هو ترتيب الرحلة. البرامج اللي بين `onair` و`bts` بتظهر تلقائيا على حيطة الكنترول
(الحيطة 3×3، يعني 9 برامج).

قيم `mood` المتاحة: `letterbox` (شرايط سينما)، `wave` (خطوط صوت)، `speed` (خطوط حركة)، `tally` (إطار بث مباشر)،
`paint` (شاشات مايلة زي اللوحات)، `rundown` (كروت فقرات)، `warm`.

## روابط المشاركة

كل مشهد له رابط: `…/#mawjat`، `…/#documentary`، إلخ. زرار «انسخ اللينك» جوه الورقة بينسخه.

## القرارات الإبداعية

- **الفكرة:** «قبل الهوا.. الحكاية لسه بتتكتب». الزائر بيدخل غرفة الكتابة بعد التصوير، وبيخرج من باب الكنترول.
- **التوقيع:** كل شاشة بتبدأ **ورقة سكريبت** عليها جملة من الشغل، وبتتقلب وتبقى الصورة وإنت بتقرب.
  ده المعنى الحرفي لجملة «بدأت في يوم بكلمتين على ورقة».
- **الخيط التاني:** التايم كود (6 دقايق على 25 إطار) مربوط بالسكرول، واللمبة الحمرا بتنور عند «على الهوا» وبتطفي في الآخر.
- **المساران:** الرحلة الكاملة بالسكرول، أو زرار «الشغل» اللي بيفتح كل البرامج وورقة كل برنامج من غير أي انتظار.
- **شخصية لكل برنامج:** الوثائقي بشرايط سينما، موجات بخطوط صوت، التغطيات بإطار بث وألعاب نارية حقيقية،
  مساء أبوظبي بكروت فقراته، أوتو بلس بخطوط حركة، تعابير بشاشات مايلة.
- **ليه من غير React أو GSAP:** الموقع ثابت على GitHub Pages، وthree.js لوحده كفاية. أقل تعقيد وأسرع تحميل.

## اللي مش حقيقي في الموقع (وليه)

- **غرفة الكتابة** مشهد 3D مبني بالكود، مش تصوير لمكان فعلي.
- **ملاحظات الهامش** وتلميحات العناصر (القهوة، الأباجورة) لمسات إبداعية بصوت الكاتب، مش وقائع عن عمل بعينه.
- **الجمل على ورق السكريبت** مأخوذة من نصوص الموقع نفسها، مش مقتطفات من سكريبتات الحلقات (غير متوفرة).
- كل صور وفيديوهات الأعمال والكواليس حقيقية ومن المصدر الأصلي. مفيش صور مولّدة.

## الأداء والتوافق

- جودة تلقائية: لو الإطارات بطيئة بتقل الدقة، وبعدين التوهج، وبعدين عدد الجزيئات. `?q=high` بيقفل ده للاختبار.
- من غير WebGL2 أو لو السكريبت ما اتحملش: الصفحة بتتعرض كمقال عادي بكل النصوص والصور والروابط.
- `prefers-reduced-motion`: الكاميرا بتنقل من غير حركة، والورق ما بيتقلبش، والفيديوهات ما بتشتغلش لوحدها.
- لوحة المفاتيح: الأسهم وPageUp/PageDown والمسافة للتنقل بين المشاهد، وEsc بيقفل النوافذ.
- الفيديوهات صامتة دايما إلا الريل لما تفتحه بنفسك.
